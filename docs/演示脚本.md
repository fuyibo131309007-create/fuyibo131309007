# 约120秒产品演示

1. **0–15秒：用户目标**。说明希望理解某个指数最近的市场状态、主要矛盾和未决问题。打开观市，确认真实来源与截至交易日。
2. **15–35秒：生成研究**。选择沪深300、近20个交易日，点击“生成复盘”。展开取数计划，展示交易日历、历史日线和解读的实际状态。
3. **35–60秒：核验结论**。观察结构标签、区间收益和成交活跃度，强调这是历史状态描述。点开“成交活跃度”证据，展示来源、单位、原始输入与公式。
4. **60–85秒：主要矛盾与边界**。查看风格代理与市场宽度；有同日宽度时展示支持或冲突，缺失时解释为何不能外推全市场。展示“什么会改变判断”和证据支持度的含义。
5. **85–105秒：继续研究**。点击“哪些风险变量值得继续核验？”，展示沿用实际截至日与证据指纹的追问。模型失败时，明确显示规则解读。
6. **105–120秒：可复现与交付**。切换官方历史回放，确认截至2026-08-31的标识；导出复盘。说明源码附启动方式、AI验证记录和异常测试。

录制前先跑通一遍。不要把接口失败的回退画面说成模型成功，不要以PPT代替实际操作，也不要演示买卖建议。
