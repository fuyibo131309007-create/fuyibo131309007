# 观市实施计划

目标：完成题目01的可运行研究主链路，支持真实取数、可复算结论、证据追溯、继续研究与异常降级。

1. **验证数据与范围**：首先实调交易日历、指数日线；检查接口的业务码、时间和单位。无权限时使用明确标注的上交所官方历史数据。
2. **建立分析框架**：指数结构、成交活跃度、风格代理、已实现波动、估值背景、市场宽度、事件与情绪七个维度。缺失维度不生成正常结论。
3. **完成产品流程**：选指数/窗口/截至日/来源 → 查看取数计划 → 获取状态与主要矛盾 → 核验原始字段 → 查看改变判断的条件 → 继续追问或导出。
4. **接入模型**：DeepSeek负责解释已有证据；程序负责数值、结构标签和覆盖。模型异常、引用异常或明显矛盾时明确回退为规则解读。
5. **验证与交付**：统计口径与故障测试、真实接口与模型实调、浏览器流程、类型检查、构建、部署；提供源码、README、AI验证记录、测试说明和演示脚本。

范围控制：单次按需研究，不引入持续调度、交易执行、个股推荐、持仓画像或收益预测。没有访问权限的资料不会以合成数据补齐。
