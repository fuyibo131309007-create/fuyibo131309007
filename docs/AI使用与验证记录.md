# AI 使用与验证记录

日期：2026-10-09。本文记录本次实现过程中实际发生的工作；候选人提交前应补充本人体验与修正，不能把代理完成的验证冒充个人完成。

## 使用方式

- Codex：读取题面、比较范围、编写前后端、整理官方数据契约、准备测试与文档。
- 研究与审查代理：分别核验数据契约、统计与产品边界、模型接入和输出限制。只读审查后由主代理整合修正。
- DeepSeek API：运行时解释服务端已经计算的市场证据。模型版本由环境变量配置，默认 `deepseek-flash`。模型不计算金融指标、不输出买卖指令。

## 已发现并修正的问题

|发现|修正|验证方式|
|---|---|---|
|最初把“更能展示产品能力”当成选题优先级|用户明确最容易完成后选择01，收敛为单次市场研究|逐项对照题面|
|猜测接口路径不可靠|读取官方全文，指数使用独立的 `a-share-index` 接口|真实交易日历/快照/日线调用成功|
|空时间戳可能被转换为1970年|先验证毫秒时间戳及请求范围|自动化边界测试|
|系统已收盘不代表返回快照已收盘|同时检查数据日期、时间、分页一致性与有效行情覆盖|早盘缓存、未来时间和低覆盖测试|
|历史不足仍可能计算完整窗口回撤|要求窗口加一个收盘价，缺失时不计算|60日窗口仅60个收盘价测试|
|市场宽度反证未进入归纳|加入价格结构与宽度方向相反的冲突分支|构造“指数上行、上涨占比低”的测试|
|风格收益差被标成百分数|统一使用“个百分点”|自动化测试|
|仅按维度数量评估支持度|核心均线不足、实际日早于目标日时强制降为低|缺失与过期测试|
|模型引用不存在或未覆盖维度形成事实断言|未知编号拒绝；缺失维度只允许不确定性，文本由覆盖记录替换|模型输出校验测试|
|真实模型曾把下行结构描述成“均线之上”|加入结构方向矛盾检查，失败时回退|真实输出发现 + 回归测试|
|初版方向过滤误拒“活跃度低于常态”和“均线在价格上方”|限定比较对象并保留正反句主语；来源模式也增加矛盾检查|误拒复现、主语反转与来源模式回归测试|
|重新取数可能让追问悄悄改变证据|固定实际截至日，比较证据SHA256指纹；变化返回409|指纹与接口测试|
|完整快照重新采集时间变化会导致相同数字指纹不同|指纹只包含计算事实，排除采集元信息|同数字/不同采集时间与计数变化测试|
|页面参数比较依赖JSON键顺序|改为逐字段比较|WebMCP真实调用发现并修正|

## 边界

格式、证据编号和方向检查不能证明任意生成文本完全正确。原始事实、来源、口径与模型归纳分开展示。当前不接入新闻/公告/宏观；扶摇未提供本产品需要的同日历史估值和历史宽度时，明确显示缺失。

真实接口调用和模型调用的状态应以测试说明及当前页面为准。合成序列仅存在于自动化测试，产品中的离线样本来自上交所官方响应。
