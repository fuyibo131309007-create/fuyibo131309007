# AI 使用与验证记录

日期：2026-10-09。本文记录本次实现过程中实际发生的工作；候选人提交前应补充本人体验与修正，不能把代理完成的验证冒充个人完成。

## 使用方式

- Codex：读取题面、比较范围、编写前后端、整理官方数据契约、准备测试与文档。
- 研究与审查代理：分别核验数据契约、统计与产品边界、模型接入和输出限制。只读审查后由主代理整合修正。
- DeepSeek API：运行时解释服务端已经计算的市场证据。模型版本由环境变量配置，默认 `deepseek-flash`。模型不计算金融指标、不输出买卖指令。

## 边界

格式、证据编号和方向检查不能证明任意生成文本完全正确。原始事实、来源、口径与模型归纳分开展示。当前不接入新闻/公告/宏观；扶摇未提供本产品需要的同日历史估值和历史宽度时，明确显示缺失。

真实接口调用和模型调用的状态应以测试说明及当前页面为准。合成序列仅存在于自动化测试，产品中的离线样本来自上交所官方响应。

## 题面复审的新增修正

本轮由Codex及只读审查代理对照原题、源码、真实接口和浏览器，发现并修正：

|发现|修正|验证|
|---|---|---|
|请求开始后生成的新快照被误判为未来时间|在分页结束时取校验时间，真正未来时间仍拒绝|mock时间推进回归，收盘后5579条真实快照成功|
|缺失证券代码可被Set计作唯一证券|规范化并验证代码格式，再核验完整性与唯一性|缺失、非法、大小写与空格重复、跨页故障|
|历史日线内部缺交易日仍可计算连续均线|按交易日历检查first～last实际记录，缺口停止关联指标|内部缺日、非交易日、前部截短、尾部陈旧|
|官方缓存降级抹掉目标日，使旧行情支持度偏高|保留请求截至日，旧实际日强制低支持|官方取数失败及缓存降级回归|
|证据相同但验证状态变化未改变指纹|加入请求日、覆盖和限制；追问保留原请求|指纹与HTTP一致性测试|
|初始研究问题未经过交易请求预检；部分中文同义表达漏拦截|统一有效问题预检，补常见购买/抛出/全投/收益/明日方向表达及输出检查|11组有界模型回归；不是声称真实DeepSeek注入成功|
|MA以上/以下、未知/分化结构与无依据宽度/估值/活跃度断言未完整核验|增加针对已有事实的矛盾与未覆盖断言检查|正确解释与错误断言成对测试|
|导出遗漏AI引用、冲突、支持度、输入和追问|完整Markdown及JSON导出，保留规则与AI两套归纳|内容保留、失败原因、JSON往返|
|取数计划仅表现为运行后日志|增加随指数、窗口、来源更新的运行前计划，与执行日志分开|计划变化测试及浏览器操作|

这些修正由AI代理完成；没有替候选人填写个人操作经历。当前取数计划是确定规则生成，模型负责解释，不能描述成模型自主规划和调用任意工具。

线上首次复审发现交易日历12秒超时，报告失败；本地成功不能替代线上业务验收。补充只读GET瞬时网络/5xx失败最多一次重试，401/429/业务码/格式错误不重试；超时转为明确错误并保留失败执行记录。新增4组回归，不将外部接口永久可用当作保证。

最后只读复核补充：读取JSON响应体时的TimeoutError/网络中断也必须走有限重试；只有真正SyntaxError才判为格式错误。补2组回归验证并记录为代理发现。
