# 观市 · AI 驱动的 A 股市场研究工作台

同花顺笔试题目 01 的可运行实现。帮助投资研究者理解某个指数截至已完成交易日的历史状态、主要矛盾及判断改变条件。支持四个指数、20/60 个交易日窗口、证据追溯、继续研究和 Markdown 导出。

**在线体验：[观市 · A股研究工作台](https://market-lens-research.k7419778603.chatgpt.site)** · [源码仓库](https://github.com/fuyibo131309007-create/fuyibo131309007)

2026-10-09 已发布，持链接即可访问。真实金融数据与模型凭证配置在服务端，不随本仓库交付。仓库作者：`fuyibo131309007-create`；AI 参与情况详见验证记录。

## 产品选择

目标用户是希望快速完成一次市场复盘、同时能核对依据的个人研究者。核心任务是“选择范围 → 看取数执行结果 → 理解状态 → 核验证据 → 研究未决问题”。本次以最容易完成且可验证为目标，收敛到指数研究；没有把持续监控、个股画像和交易执行加入首版。

- **事实**：程序计算收盘价、均线、区间收益、成交活跃度、风格收益差与已实现波动；逐项提供来源、时点、单位、公式和计算输入。
- **归纳**：透明规则固定价格结构，展示支持证据、冲突及状态切换条件。阈值是产品启发式规则，未经收益预测校准。
- **不确定性**：七个维度分别显示已核验或未覆盖。置信度是证据支持度，不是涨跌概率；缺失、过期、接口失败及模型回退均可见。

## 启动

需要 Node.js ≥22.13.0 和 npm。项目根目录执行：

```bash
npm ci
npm run setup:local
# 可选：编辑 .env.local，填写自己的服务端密钥
npm run dev
```

浏览器打开终端打印的地址，默认 `http://127.0.0.1:5173/`。无密钥也可操作“官方历史回放”，使用真实上交所公开响应缓存，范围为 **2026-06-01～2026-08-31**，清楚标注为历史样本。

`setup:local` 创建不进入 Git 的 `.env.local` 和本地 Worker 使用的 `.dev.vars` 链接。Windows 若不支持链接，可将 `.env.local` 复制为 `.dev.vars`。修改配置后重启服务。

|变量|用途|必填|
|---|---|---|
|`FUYAO_API_KEY`|扶摇交易日历、指数历史及同日全 A 快照|否；未配置使用官方历史回放|
|`DEEPSEEK_API_KEY`|基于已有证据生成中文解读|否；未配置使用规则解读|
|`DEEPSEEK_BASE_URL`|模型 API 地址，默认 `https://api.deepseek.com`|否|
|`DEEPSEEK_MODEL`|模型名称，默认 `deepseek-flash`|否|

密钥只在服务端使用，不通过 `/api/config`、页面、证据或报告返回。仓库不包含密钥、真实扶摇响应或用户数据。模型调用会将本次市场证据和研究问题发送至配置的 DeepSeek 服务；不需要填写个人信息或持仓。

## 数据与分析口径

1. **扶摇接口研究**：先读取交易日历，再获取四个指数的历史日线。上海时间 15:30 前不使用当日收盘研究；研究日取最近已完成交易日。只有研究日等于今日且收盘后，才尝试完整分页获取全 A 快照，并核验时间、总量、重复证券及至少 90% 的有效行情覆盖。
2. **官方历史取数**：按需请求上交所公开月报。月报存在延迟；失败时显式标注历史缓存降级，报告显示实际有效日期。
3. **官方历史回放**：固定公开样本。`data/official/` 保存归一化数据、18 份用于回放的原始响应及 SHA256 校验值，另有 2 份公开接口探测响应，便于复核。历史样本不会充当当前行情。

|维度|口径与范围|
|---|---|
|价格结构|收盘价同时高于 MA20/MA60 为上行结构，同时低于为下行结构，其间为分化；历史不足不强判|
|成交活跃度|所选指数近 5 日均成交额 / 近 20 日均成交额；不是全 A 成交额或资金净流向|
|风格代理|相同起止日，科创 50 收益率减沪深 300 收益率，单位为百分点；不是完整风格轮动|
|已实现波动|近 20 个日收益率的样本标准差，需 21 个收盘价；不年化、不预测|
|估值背景|官方模式可提供同日沪市分板平均市盈率；不是所选指数 PE、TTM 或估值分位|
|市场宽度|同日完整快照上涨家数 /（上涨＋下跌家数），平盘及无效行情不进入分母；历史快照缺失则不生成|
|事件与情绪|当前未接入，明确显示未覆盖；未检索不等于没有事件|

20/60 日收益需要 21/61 个收盘价；用于计算均线的历史单独获取。支持度按可用维度提示，核心历史不足或实际行情早于目标日时降为低。详细数据契约见 [CONTRACTS.md](data/official/CONTRACTS.md)。

来源：[扶摇文档](https://fuyao.aicubes.cn/docs/)、[上交所指数月报](https://www.sse.com.cn/aboutus/publication/monthly/index/)、[分板月报](https://www.sse.com.cn/aboutus/publication/monthly/report/)、[指标定义](https://www.sse.com.cn/aboutus/publication/monthly/explain/)。

## AI 的角色

DeepSeek 只解释服务端已经计算的证据，不修改数值、来源或结构标签。输出经过结构、证据编号、数字断言及明显方向矛盾校验；超时、限流、授权失败或校验失败时，界面说明原因并保留规则解读。此校验不构成任意文本的完整事实证明。

继续研究固定报告实际截至日，并由服务端重新取数比较证据指纹。证据发生变化返回 `409 SNAPSHOT_CHANGED`，要求刷新报告，避免追问悄悄换用另一份事实。买卖、仓位、荐股及确定性涨跌问题转向研究边界提示。

AI Coding 的使用、实际发现的问题和修正见 [AI 使用与验证记录](docs/AI使用与验证记录.md)。候选人的个人体验与验收应据实补充。

## 技术结构与验证

React / TypeScript + Vinext，服务端运行于 Cloudflare Workers 兼容环境。无需数据库；密钥配置在运行环境。`app/api/` 提供研究与追问接口，`lib/market/` 负责数据适配、计算、模型及证据一致性，`components/market-workspace.tsx` 提供交互工作台。支持 WebMCP 的浏览器可调用 `get_market_report` 与 `run_market_research`，普通浏览器不依赖此能力。

```bash
npm test                 # 实际 TypeScript 实现的统计/异常边界测试
npm run check            # TypeScript 类型检查
python3 tests/integration.py  # 先启动本地服务；含真实接口调用，可能消耗模型额度
npm run build            # 构建 Worker 和前端资源
npm start                # 本地预览构建产物
```

[测试说明与执行结果](docs/测试说明.md) · [实施计划](docs/实施计划.md) · [约 120 秒演示脚本](docs/演示脚本.md)

部署使用项目已有的 Sites 配置：`.openai/hosting.json` 只记录托管绑定，生产密钥配置在托管平台运行环境。其他托管环境需要支持 Cloudflare Workers API；不能仅将静态页面上传到 GitHub Pages。

## 当前边界与未做事项

- 不提供直接买卖、仓位、价格目标或收益承诺。结构是历史描述，不是未来方向预测。
- 未接入 iFinD、新闻、政策、宏观、行业成分、历史全 A 宽度、指数估值分位；不使用合成数据补齐产品缺口。
- 四个指数与一对风格代理不能代表完整 A 股市场。成交活跃度不能代替宏观流动性，指数涨跌不能代替市场宽度。
- 不包含账户、持仓、持续定时监控、通知、数据库或跨设备报告保存。刷新后可重新研究，也可导出保存。
- 首版用于笔试演示。未完成多用户并发负载、长期稳定性与商业服务容量验证。演示视频是可选交付；当前提供脚本。
